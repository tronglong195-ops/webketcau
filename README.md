## 🌟 TỔNG QUAN DỰ ÁN

Website là một **sổ tay số hóa học tập cá nhân** dành cho sinh viên, kỹ sư kết cấu xây dựng và người tự học, chuyển hóa toàn bộ lý thuyết hàn lâm từ bộ sách 3 tập của Thầy Võ Bá Tầm thành các bài học trực quan sinh động với:
1. **Đúng kỹ thuật & Đủ kiến thức**: Độ phủ **100% (160/160 mục)** theo mục lục sách gốc.
2. **Trực quan & Dễ hiểu**: Mọi cấu kiện đều tích hợp mô hình 3D tương tác (Three.js), hiển thị rõ lồng cốt thép, vùng nén bê tông, biểu đồ ứng suất và vết nứt.
3. **Thẩm mỹ & Hiện đại**: Giao diện tối ưu chuẩn kỹ thuật, hỗ trợ mượt mà từ màn hình máy tính lớn đến điện thoại di động (Mobile First).

## 📚 ĐỘ PHỦ NỘI DUNG (160/160 MỤC HOÀN THÀNH)

### 📘 Tập 1: Cấu Kiện Cơ Bản (69/69 mục — 100%)
- **Chương 1**: Khái niệm chung về BTCT, phân loại, ưu khuyết điểm, phạm vi ứng dụng.
- **Chương 2**: Tính chất cơ lý của bê tông, cốt thép, biểu đồ ứng suất – biến dạng ($\sigma - \varepsilon$), cấp độ bền B, nhóm thép CB.
- **Chương 3**: Nguyên lý tính toán hai trạng thái giới hạn (THGH 1 & THGH 2), hệ số độ tin cậy.
- **Chương 4**: Cấu kiện chịu uốn: Tiết diện chữ nhật (cốt đơn, cốt kép), tiết diện chữ T, chữ I, tính độ bền tiết diện nghiêng theo lực cắt, biểu đồ bao vật liệu.
- **Chương 5**: Cấu kiện chịu nén: Nén đúng tâm, nén lệch tâm phẳng (lệch tâm lớn & lệch tâm bé), nén lệch tâm xiên.
- **Chương 6**: Cấu kiện chịu kéo: Kéo đúng tâm và kéo lệch tâm.
- **Chương 7**: Tính toán theo trạng thái giới hạn thứ hai: Chống nứt ($a_{crc}$) và độ võng ($f \le [f]$).
- **Chương 8**: Cấu kiện chịu uốn – xoắn đồng thời.
- **Chương 9**: Sàn bê tông cốt thép: Bản kê 4 cạnh, bản dầm 1 phương, phương pháp khớp dẻo.
- **Đồ án BT1**: Thiết kế sàn sườn toàn khối loại bản dầm đầy đủ thuyết minh và quy cách thép.
- **Phụ lục Tập 1**: Bảng tra cứu cường độ vật liệu $R_b, R_{bt}, R_s, R_{sc}, R_{sw}, \xi_R, \alpha_R$.

### 📙 Tập 2: Cấu Kiện Nhà Cửa (39/39 mục — 100%)
- **Chương 1**: Các hệ kết cấu sàn: Sàn sườn toàn khối, sàn nấm (không dầm), sàn panen lắp ghép.
- **Chương 2**: Khung bê tông cốt thép toàn khối và lắp ghép, nút khung, cấu tạo cốt thép khung nhà nhiều tầng.
- **Chương 3**: Móng bê tông cốt thép: Móng đơn nông, móng băng dưới tường và dưới cột, kiểm tra chọc thủng tháp $45^\circ$.
- **Chương 4**: Nhà công nghiệp một tầng lắp ghép: Khung ngang, cột chữ I, cột phân cành, giằng, vai cột.
- **Chương 5**: Kết cấu mái nhà công nghiệp: Dầm mái, dàn mái BTCT.
- **Phụ lục Tập 2**: Bảng nội lực và quy cách cấu tạo nhà dân dụng & công nghiệp.

### 📕 Tập 3: Các Cấu Kiện Đặc Biệt (52/52 mục — 100%)
- **Chương 1**: Cầu thang bộ BTCT: Cầu thang bản dầm, cầu thang có cốn, cầu thang xoắn ốc dạng côngxôn.
- **Chương 2**: Bể chứa chất lỏng: Bể chữ nhật ngầm, bể nổi, bể nước tròn, bể nước mái sinh hoạt.
- **Chương 3**: Tường chắn đất BTCT: Tường chắn góc, tường chắn có sườn, tính áp lực chủ động của đất.
- **Chương 4**: Silô và Bunke: Kết cấu chứa vật liệu rời.
- **Chương 5**: Kết cấu mái vỏ mỏng không gian: Vỏ trụ, vỏ nón, mái vòm vỏ mỏng.
- **Chương 6**: Cấu kiện chịu xoắn đặc biệt.
- **Phụ lục Tập 3**: Bảng tra hệ số mômen tấm bản mỏng và biểu đồ nội lực bể.

## 🚀 TÍNH NĂNG NỔI BẬT TRÊN WEBSITE

1. **Phòng Thí Nghiệm 3D Tương Tác (Three.js)**:
   - Xoay 360°, thu phóng, quan sát lồng cốt thép bên trong bê tông.
   - Chế độ **X-Ray (Xuyên thấu)** / **Chỉ xem cốt thép (Rebar Only)**.
   - Trực quan hóa mặt cắt nén bê tông (Stress Block), biểu đồ biến dạng (Strain Profile) và vết nứt nghiêng (Shear Cracks).
   - Tối ưu cử chỉ cảm ứng trên mobile: 1 ngón xoay, 2 ngón zoom, nút điều khiển lớn $\ge 44\text{px}$.

2. **Dự Án Thực Tế Mẫu Toàn Diện (Tòa Nhà Văn Phòng 5 Tầng)**:
   - Hồ sơ tính toán mẫu liên hoàn từ đầu đến cuối:  
     $$\text{Sàn dầm} \rightarrow \text{Dầm phụ } (20 \times 40) \rightarrow \text{Dầm chính khung } (25 \times 60) \rightarrow \text{Cột lệch tâm } (30 \times 40) \rightarrow \text{Móng đơn } (2.4 \times 1.8\text{m}) \rightarrow \text{Thang bộ & Bể nước mái}$$
   - Tích hợp bộ máy tính cột tự động đổi số liệu $N, M, b, h$ theo thời gian thực.

3. **Hệ Thống Công Thức KaTeX Chuẩn Mực**:
   - 100% công thức và ký hiệu toán học được biên dịch qua KaTeX sắc nét, có nguồn gốc trích dẫn số trang sách cụ thể (ví dụ: `T1 tr.65`, `T2 tr.124`).
   - Hỗ trợ nút sao chép mã LaTeX nhanh chỉ với 1 chạm.

4. **Bộ Công Cụ Kiểm Tra & Tra Cứu**:
   - Tra cứu cấp độ bền bê tông (B15 – B40) và nhóm cốt thép (CB240-T, CB300-V, CB400-V).
   - Tra cứu ký hiệu kết cấu chuẩn ngành xây dựng.
   - Flashcards ôn tập nhanh câu hỏi lý thuyết kết cấu.

5. **Trải Nghiệm Mobile Thông Minh (Mobile First)**:
   - Nút nổi **📑 Mục lục chương** trượt mượt mà (Bottom Sheet) giúp nhảy nhanh đến đúng đề mục mà không phải vuốt màn hình nhiều lần.
   - Bảng tra và công thức có vùng cuộn ngang chống tràn màn hình.

## 🛠️ CÔNG NGHỆ SỬ DỤNG (TECH STACK)

- **Frontend**: React 18, TypeScript, Vite 5.
- **Đồ họa 3D**: Three.js, `@react-three/fiber`, `@react-three/drei`.
- **Giao diện & Hiệu ứng**: Tailwind CSS, Framer Motion.
- **Công thức toán**: KaTeX, `remark-math`, `rehype-katex`.
- **Điều hướng tĩnh**: React Router v6 (`HashRouter` chống lỗi 404 trên GitHub Pages).
- **Kiểm thử**: Vitest, script kiểm tra độ phủ tự động (`scripts/check-coverage.ts`).

## 💻 HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN CỤC BỘ

### Yêu cầu môi trường
- **Node.js**: Phiên bản $\ge 18.0.0$
- **npm** hoặc **pnpm / yarn**

### 1. Tải mã nguồn về máy
```bash
git clone https://github.com/tronglong195-ops/webketcau.git
cd webketcau
```

### 2. Cài đặt thư viện dependencies
```bash
npm install
```

### 3. Chạy môi trường phát triển (Dev Server)
```bash
npm run dev
```
Mở trình duyệt tại địa chỉ: `http://localhost:5173/`

### 4. Chạy kiểm tra chất lượng & Đóng gói sản phẩm
```bash
# Chạy Unit Tests thuật toán tính toán kết cấu
npm test

# Kiểm tra độ phủ 160/160 mục giáo trình
npm run check-coverage

# Build bản tối ưu cho production
npm run build
```

### 5. Cập nhật và Deploy lên GitHub Pages
Dự án đã tích hợp sẵn script triển khai tự động chỉ với 1 câu lệnh:
```bash
npm run deploy
```
Lệnh này sẽ tự động kiểm tra test, build sản phẩm và đẩy thẳng lên nhánh `gh-pages` của GitHub.
